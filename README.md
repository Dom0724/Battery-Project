# Battery-Project
By Dominik Swieboda, 09/2026

A project to simulate and model the behaviour and performance of an electric bicycle battery under different use and background conditions using MATLAB, Simulink and Simscape. 

Version1: Setting up and testing battery parameters

Version2: Introducing current controller + soc estimating algorithm

Version3: Prevention of battery over draining + charge/discharge cycle

Version4: Different Constant Temperature Conditions
